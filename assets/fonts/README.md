# Web typography

Geist variable (100–900), from the Geist Project by Vercel.

- Source: https://github.com/vercel/geist-font
- Web subsets: Google Fonts, Geist v5 (downloaded 16 October 2026)
- License: SIL Open Font License 1.1; see `geist-OFL.txt`.

Files are hosted by StreamArena. Unicode ranges load only the subsets used by
the page; the Latin subset is preloaded. No font service is contacted at runtime.

The previous Manrope variable font (400–800) remains available for rollback.
Source: https://github.com/google/fonts/tree/main/ofl/manrope
License: SIL Open Font License 1.1; see `OFL-Manrope.txt`.
